Customer Management System – Python GUI Project

A desktop-based Customer Management System built using Python, MySQL, and Tkinter.

🚀 Features

Add, Search, Update & Delete customer records
MySQL database integration using PyMySQL
Tkinter based GUI interface
Display all customer data in tabular format using Treeview
Handles real-world database issues like authentication and deadlocks
